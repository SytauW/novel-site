# 《跟着光走》 · 十六个近未来短篇

一部非商业的科幻短篇集阅读站，由 GitHub Pages 托管。

## 关于本书

设备退了场，身份登场。人只保留挑选，付款与配送交给系统和机器；地上的光带替你选路，耳机里的声音替你措辞，每一天的记忆自动归档成四行摘要。所有人好像都成了精英，真实的人性却没有成长。

全书 **16 篇、四辑**，故事时间为 **2036 年**（系统普及元年 2030 年）。各篇独立成篇，不靠单一主角串场，靠母题与物件彼此照面：

| 辑 | 篇目 | 主题 |
|---|---|---|
| 辑一 · 世界很亮 | 01–04 | 光先亮起来，人还以为日子是自己的 |
| 辑二 · 系统比我更懂我 | 05–08 | 它开始替你回答，比你自己答得更像你 |
| 辑三 · 你是你的存档吗 | 09–12 | 账目、产权、版本都能证明你在，唯独证不出你 |
| 辑四 · 快乐至上 | 13–16 | 所有温柔都到了场，也全都成了囚禁 |

## 本站收录范围

**只收录第四版定稿的 16 篇正文。** 世界观设定集、伏笔台账、全书编年表、结构目录、修订清单、逐条差异、质检报告等过程文档一律不在本仓库内，也不对外发布。

## 阅读说明

- 正文里带 `▸` 的是**智体、系统或设备**的发声；人说话永远不带这个符号。站内给该符号做了统一的等宽与主色标识。
- 屏上一行小字／光字用行内等宽样式；系统回执、版本日志、账单条目用代码块呈现。
- 有若干篇采用**工单、邮件往来、投诉笔录、年度结算单、版本日志、评估报告、舞台提示**等形式。字段头与标题是刻意的文体实验，不是排版错误。
- 右上角「字」切换三档字号，「◐」切换浅色／深色／跟随系统，偏好记在浏览器本地。
- 纯静态页面，无外部字体、无 CDN、无统计脚本，可离线阅读。

## 技术说明

零构建、零依赖的静态站点，GitHub Pages 从分支根目录直接托管即可，不需要 Node、Jekyll 或任何 CI。

```
.
├── index.html          目录页 + 关于
├── chapters/
│   ├── 01.html … 16.html
├── assets/
│   ├── style.css       排版、明暗主题、▸ 系统话语样式
│   └── app.js          字号 / 主题切换（localStorage）
├── .nojekyll           跳过 Jekyll 处理
└── README.md           本文件
```

页面由本地脚本把第四版 Markdown 正文转成 HTML 后生成；**生成脚本不在本仓库内**，仓库只保留可直接阅读的成品。

## 开启 GitHub Pages

1. 把本仓库推送到 GitHub。
2. 仓库 **Settings → Pages**。
3. **Build and deployment** 里 Source 选 `Deploy from a branch`。
4. Branch 选 `main`，目录选 `/ (root)`，保存。
5. 等待约一分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

若使用自定义域名，可在 Pages 设置里填写并在仓库根添加 `CNAME` 文件。

## 本地预览

直接双击 `index.html` 即可；或在本目录起一个静态服务：

```bash
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```
